## 4. خصوصية التطبيق (App Privacy)

**Data Collection: Yes.** كل البيانات «Linked to the user»، والغرض **App Functionality** فقط. ما فيه تتبع (Tracking: **No**).

| النوع في Apple | ليش |
| --- | --- |
| Contact Info → Email Address | تسجيل الدخول والإيميلات |
| Contact Info → Name | اسمك في صفحتك |
| Contact Info → Phone Number | رقم الواتساب في صفحتك (اختياري) |
| User Content → Photos or Videos | صورتك، شعارات الشركات، أعمالك |
| User Content → Other User Content | النبذة، الأسعار، الروابط، صور التوثيق |
| Identifiers → User ID | حسابك، ورمز الإشعارات |
| Financial Info → Other Financial Info | الآيبان لصرف العمولة (اختياري) |

ما نجمع: الموقع، جهات الاتصال، السجل، بيانات التشخيص من التطبيق، أو الإعلانات.

## 5. ملاحظات للمراجع (App Review Information)

**Sign-in required: Yes.**
- User name: الإيميل اللي تحطه في Netlify كـ `REVIEW_EMAIL` (مثال: `review@wsool.link`).
- Password: الرمز اللي تحطه كـ `REVIEW_CODE` (8 إلى 10 أرقام).

**Notes (بالإنجليزي، انسخها كما هي):**
```
Wsool is a media kit platform for content creators. The app is the creator's dashboard for their public page (wsool.link/username).

Sign in: enter the review email above, tap "Send code", then enter the code from the Password field. (Regular users receive a one-time code by email; this review account uses a fixed code.)

Account deletion: Account tab → Subscription → "Delete my account" (type the username to confirm).

Purchases: the app sells nothing. Wsool is a multiplatform service (guideline 3.1.3(b)); the plan is shown read-only, with no prices, purchase buttons or links to buy.

Photos are chosen with the system photo picker; the app never requests access to the whole library.
```

قبل التقديم: أدخل بحساب المراجعة في التطبيق مرة وحدة، وعبّ له صفحة فيها بيانات (اسم، صورة، حسابين، أسعار)، عشان المراجع ما يشوف صفحة فاضية.

## 7. خطوات النشر (لما يتفعّل حساب Apple Developer)

1. App Store Connect → My Apps → **+** → New App: Platform iOS، الاسم أعلاه، اللغة الأساسية Arabic، Bundle ID ‏`link.wsool.app`، SKU ‏`wsool-ios`.
2. expo.dev → المشروع `wsool-app` → Credentials → iOS: سجّل دخول بحساب Apple، وExpo يسوي الشهادات تلقائياً (Distribution + Push).
3. expo.dev → Builds → Build from GitHub: الفرع `main`، المنصة iOS، الملف `production`، وفعّل **Auto submit** (يرفعه لـ TestFlight).
4. في Netlify أضف `REVIEW_EMAIL` و`REVIEW_CODE` (Contains secret values).
5. جرّب على جوالك من تطبيق TestFlight، ونأخذ صور المتجر من الآيفون.
6. عبّ الخانات من هذا الملف، وارفع الصور، واختر البناء، وقدّم للمراجعة (Submit for Review).
